# 予測対象と買い方の探索

探索の結果です。購入判定には使いません。

良い結果が出た条件も、結果を記録し、版の登録と前向き検証を経て確認します。
結果の良否にかかわらず、この報告を `docs/experiments/<日付>-<名前>.md` に記録します。

各区間は未補正の 95% 区間です。差がない場合でも 5% 前後はゼロをまたがないことがあります。対象や銘柄の値動きは連動するため、区間や銘柄の数を独立した確認の回数としては扱えません。

Model B の結果が当てはまるのは、ここで使った 5 特徴量とモデルの組み合わせです。原油、金、信用スプレッド、経済統計やニュースの有効性は別途検証が必要です。共通ルールは探索用で、条件の最適性は未確認です。

### 4. 新しい予測対象(Model A、全検証行)

- 期間内に一定以上下がる確率(`drop*`): S&P500 は AUC 0.59〜0.65 で、4 通りとも区間が 0.5 を上回る。FANG+ で上回るのは `drop5_10`(0.586)だけ、オール・カントリーは 0.43〜0.53 でどれも上回らない。S&P500 でも Brier スキルは −0.006〜+0.031 で区間がゼロをまたぐ(並べ替える力は見えるが、確率の値が基準の正例率より良いとは言えない)。
- 騰落率(`ret5`、`ret10`、`ret20`): スキルは 3 銘柄とも負(−0.05〜−0.27)で、9 つのうち 7 つは区間がゼロを下回る。学習時点の平均をそのまま使うより誤差が大きい。
- 最大下落率(`low20`): スキルは負。順位相関は S&P500 だけ区間がゼロを上回る(+0.124)。オール・カントリーは下回る(−0.156)。
- ボラティリティ(`vol20`): 順位相関は 0.40〜0.58 で、3 銘柄とも区間がゼロを上回る。スキルは S&P500(+0.38)とオール・カントリー(+0.26)が上回り、FANG+(−0.03)は有効性未確認。値動きの大きさが続きやすいという知られた性質と合う。方向を持たないので、買い方には変換していない。

### 5. 共通ルールの買い方

- 定期購入、一括、偽シグナルより安く買えた(区間の上限がゼロ未満の)買い方は、3 銘柄とも 0。買い方ごとの 120 区間のうち「不利」は FANG+ 56、S&P500 52、オール・カントリー 86。
- 「A の登録の買い方」との差でも、有利の区間は 0。
- 買い方の B − A では、有利の区間が S&P500 に 29、オール・カントリーに 13 ある(`ret*` の共通ルール、S&P500 ではほかに `down20` の共通ルールと、基準価額の期間の `drop*`)。これは Model A のその買い方が不利だったぶん、Model B の不利が小さいという差で、Model B の買い方が定期購入より安いことを示さない(Model B の買い方も、有利の区間は 0)。

### 6. 試した数

銘柄ごとに 414 の区間を出した(未補正の 95% 区間)。差がまったくなくても、その 5% 前後(約 20)は基準をまたがない。対象どうし、銘柄どうしは連動する。上の 4 節と 5 節で区間が基準をまたがなかったものは、この数の中で読む。

### 7. 抜き取り確認

- 今回の実装(`macro`、`explore`、`ledger`、`ml` の変更)を使わずに別に書いた計算で、3 銘柄の 99 項目を突き合わせ、すべて一致した。点推定は小数 6 桁まで、区間は乱数の種が違うので幅の 15% 以内。対象は、行数、ML v1 の件数・AUC・Brier スキル、`down20` の A・B とその差(全検証行と基準価額の期間)、主条件の買い方の件数と平均(`ml`、`ml-macro`)、探索の買い方の B − A、`drop5_20`、`ret20`。
- マクロ指標の 5 特徴量は、別計算と全国内営業日で一致した(差 0、欠けの位置も同じ)。1986 年以降、5 営業日を超える抜けで欠けた日はない。
- 既存の出力は変更の前と一致した(`ml/<id>.json` は差なし、`backtest/<id>.json` は `ml-macro` が増えただけ。`latest.json` と `series` の最終日の差は、為替の取得時刻の違い)。
- 探索の Model A の `down20` の予測は、毎日のビルドの ML v1 と 3 銘柄とも全行で一致した(確率の最大絶対差 0)。マクロ指標のために除いた行は 0。

### 8. 読み方の限界

- Model B の結果は、この 5 特徴量とこのモデル(ロジスティック回帰)についてのもの。原油、金、信用スプレッド、経済統計、ニュースの有効性については何も示さない。
- 共通ルールは探索用で、最もよい条件だと確かめたものではない。
- ドル指数は、日足の終値が朝に確定している保証がないので 1 日遅らせて使っている。金利は VIX と同じ扱い(遅れなし)。
- 過去データの検証で、前向きの確認ではない。
